## Design recommendation for TREARABIA.com

Goal: a modern, interactive, "smart" site that reads as clinically credible *and* warm/somatic — matching the brand palette already set in the MOVE x TRE Arabia partnership proposal (Deep Obsidian Navy #0B132B, Warm Saudi Gold #C5A059, Sage Somatic Green #8A9A86, Pure Slate White #F8F9FA; Cormorant Garamond display + Inter/Proxima Nova body).

Priority order to actually draw from:

1. **TRE Global (official site)** — use for information architecture and copy authority (What Is TRE, provider/certification structure, method explanation). This is the trust anchor; don't deviate from its factual framing of the method.
2. **Choosing Therapy** — best UX/content-pattern reference of the five: clean progressive-disclosure layout (benefits → types → how it works → getting started), approachable for a first-time visitor. Good template for how TREARABIA.com should structure its "What is TRE" and "Getting Started" sections with modern card/accordion patterns.
3. **TRE Healing (7 Exercises guide)** — reference for an interactive step-by-step exercise walkthrough module (e.g. a scroll- or click-through component with illustrations/short video per exercise) — this is where "interactive" and "smart" can really show up on TREARABIA.com.
4. **TRE Global "What Is TRE"** — pull messaging/explainer copy structure, not visual design (site itself is visually dated).
5. **Wikipedia** — skip for design entirely; useful only as a citation/fact-check source, not a UX or visual reference.

Practical takeaway: lean on Choosing Therapy for modern layout/interaction patterns, TRE Global for authoritative content, and TRE Healing for an interactive exercise-guide component — then apply the existing Navy/Gold/Sage palette and Cormorant Garamond + Inter type system on top, rather than copying any site's visual style directly.
