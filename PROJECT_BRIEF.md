## Interactive features already built

- **Bilingual EN/AR toggle** (`#lang-toggle` button): swaps all `data-en`/`data-ar` attributed text, flips `dir` to `rtl`, switches body font to Cairo, persists choice in `localStorage`.
- **Scroll-reveal animation**: `.reveal` class + `IntersectionObserver` in `script.js`, fades/rises elements into view once.
- **Cache-busting**: `styles.css` and `script.js` are linked with `?v=N` query params — **increment the version number on every deploy** that changes CSS/JS, or GitHub's CDN / browsers may serve stale cached versions.
